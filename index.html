A Claude Code plugin

Meet Clawd, your pixel coding buddy.

Clawd sits in your status line, a small window and your Mac menu bar. It reacts to what Claude Code is doing, tells you when it needs your OK, and reminds you to drink water.

Which colour wins

The model's colour comes first. If it is set to none, Clawd uses your main colour, and classic if nothing is set.

model colour→Clawd colour→classic

Commands

Four commands, that's it

/clawd-companion:setup

Installs the status line, asks what Clawd should call you, and backs up your settings first.

/clawd-companion:open

Opens the companion window beside your terminal.

/clawd-companion:stop

Closes the window's server and the menu bar Clawd.

/clawd-companion:uninstall

Removes Clawd and puts your old status line back.

Every setting lives in /plugin → clawd-companion → Configure.

Reminders and notices

Small nudges, never in the way

Drink water

45min · 20sec

Every 45 minutes Clawd holds up a glass for 20 seconds. Set both to whatever you like. It never interrupts a permission prompt.

Time to Drink water, <name>! · One glass. Then back to it.

Approval alerts

1tap

When Claude Code needs your OK, Clawd waves and turns gold. On a Mac you also get a notification that takes you back to the terminal.
